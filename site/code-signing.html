Podpisywanie kodu (Code signing policy)

Ostatnia aktualizacja: 13 listopada 2026

Stan: wniosek o darmowe podpisywanie jest w przygotowaniu. Obecne wydania na Windows nie są jeszcze podpisane tym certyfikatem, dlatego SmartScreen może pokazać ostrzeżenie.

Po przyjęciu projektu: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Co jest podpisywane

  • Pliki Aeriona na Windows: instalator Aerion_x.y.z_x64-setup.exe, AerionSetup.exe oraz zawarte w nich programy aerion.exe i AerionUninstall.exe.
  • Wyłącznie pliki zbudowane z kodu w publicznym repozytorium. Projekt nie zawiera zamkniętych składników. Licencja: GPL-3.0.

Jak powstaje wydanie

  • Wydania buduje automatycznie GitHub Actions z oznaczonej wersji kodu (release.yml). Nikt nie buduje ich ręcznie na własnym komputerze.
  • Każde podpisanie wymaga ręcznego zatwierdzenia przez osobę z roli „Approvers”.
  • AerionSetup.exe pobiera instalator Aeriona tylko z wydań tego projektu na GitHubie i przed uruchomieniem sprawdza jego podpis. Gdy w systemie brakuje składnika WebView2, instalator pobiera go od Microsoftu.
  • Aerion instaluje się w folderze użytkownika, bez uprawnień administratora, i ma własne odinstalowanie.

Zespół i role

  • Committers and reviewers: 0giel
  • Approvers: 0giel

Zmiany od osób spoza zespołu są przeglądane przed włączeniem. Konta zespołu używają logowania dwuetapowego.

Prywatność

Aerion nie zbiera danych i łączy się tylko z usługami potrzebnymi do działania. Szczegóły: polityka prywatności.

Zgłaszanie problemów

Jeśli podpisany plik Aeriona zachowuje się podejrzanie, napisz na aerion.launcher@proton.me albo zgłoś to w issues.

Code signing policy

Last updated: November 13, 2026

Status: the application for free code signing is being prepared. Current Windows releases are not yet signed with this certificate, so SmartScreen may show a warning.

Once the project is accepted: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

  • Aerion's Windows files: the installer Aerion_x.y.z_x64-setup.exe, AerionSetup.exe, and the programs inside them, aerion.exe and AerionUninstall.exe.
  • Only files built from the code in the public repository. The project has no proprietary components. License: GPL-3.0.

How a release is made

  • Releases are built automatically by GitHub Actions from a tagged version of the code (release.yml). Nobody builds them by hand on their own computer.
  • Every signing request needs manual approval by a person in the “Approvers” role.
  • AerionSetup.exe downloads Aerion's installer only from this project's GitHub releases and checks its signature before running it. When the WebView2 component is missing, the installer downloads it from Microsoft.
  • Aerion installs into the user's folder, without administrator rights, and has its own uninstaller.

Team and roles

  • Committers and reviewers: 0giel
  • Approvers: 0giel

Changes from people outside the team are reviewed before they are merged. Team accounts use multi-factor authentication.

Privacy

Aerion collects no data and connects only to the services it needs to work. Details: privacy policy.

Reporting problems

If a signed Aerion file behaves suspiciously, write to aerion.launcher@proton.me or report it in issues.
